# MedEx Neurology — نسخهٔ اولیهٔ قابل اجرا

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای انتشار رایگان، محتوای این پوشه را در مخزن GitHub Pages قرار دهید.

## محتوای واردشده
- ۱۲۰ برچسب سؤال از بانک تألیفی
- ۶۷ برچسب سؤال قابل تشخیص از فایل سؤالات استاد (عنوان فایل ۷۶ سؤال را ذکر می‌کند؛ اختلاف استخراج باید بررسی شود)
- فلش‌کارت‌های استخراج‌شده از PDF
- متن استخراج‌شدهٔ خلاصه جامع و خلاصه طلایی

## محدودیت‌های مهم نسخهٔ اولیه
- استخراج PDF متنی است و بعضی گزینه‌ها/صفحات ممکن است به‌خاطر جهت نوشتار یا قالب PDF درست تفکیک نشده باشند؛ سؤال‌های دارای نشان «نیازمند بازبینی استخراج» را قبل از استفادهٔ امتحانی با PDF اصلی تطبیق دهید.
- فلش‌کارت و فیلترها در این نسخه سمت مرورگر اجرا می‌شوند. ذخیرهٔ پایدار بین جلسات، حساب کاربری، همگام‌سازی و پنل مدیریت امن هنوز پیاده‌سازی نشده‌اند.
- در آزمون، کلیدهای نامعتبر از محاسبهٔ درصد معتبر حذف می‌شوند؛ صحت علمی محتوا نیازمند بازبینی انسانی است.
- متن خلاصه‌ها از PDF استخراج شده و ممکن است چینش نمودارها و جداول اصلی دقیقاً حفظ نشده باشد.
